Terms you need to know

Migration — With an OpenAI-compatible endpoint, migration is a base_url and api_key change; tool calling, structured output, embeddings and streaming are where compatibility diverges. (Source: editorial synthesis of public gateway docs (2026-11))

Tensoraxis Catalog — TENSORAXIS is a unified AI API gateway: one OpenAI-compatible key for 50+ upstream providers and 100+ billed models, with 50+ API routes and 10+ scheduling controls. (Source: tensoraxis.ai (verified 2026-11-18))

Fallback Billing — If a gateway fails over, you are billed at the rate of the model that actually served the request, not the one you requested. (Source: llmapi.ai comparison; vendor FAQs (2026))

Why does this matter for my workload?

The same model can be priced and routed differently across gateways. Normalise everything to cost per million input and output tokens for the models you actually call, then add the layer fee at your real volume. For a worked comparison see the Sources section.

How do I compare two gateways honestly?

  1. Normalise the unit to per-1M input/output tokens.
  2. Add the layer fee at your real volume, not the headline volume.
  3. Include cached-input discounts where available.
  4. Price the failover route at the rate of the model that serves it.
  5. Count migration effort against the monthly saving.
